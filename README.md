# 💎 VFX VAULT
**Premium 4K Chroma Key Assets for Editors**

VFX Vault is a high-end digital marketplace for high-quality VFX bundles. 
This site is optimized for mobile UPI payments and features a secure preview system.

## 🚀 Features
- **Instant UPI Payments:** Works with GPay, Paytm, and PhonePe.
- **Laptop Support:** Generates dynamic QR codes for desktop checkouts.
- **Security:** Built-in video overlays to prevent screen recording and unauthorized downloads.

## 📁 Project Structure
- `/assets/thumbnails`: Bundle cover images (`b1.png`, etc.)
- `/assets/previews`: Low-res watermarked clips (`gt1.mp4`, etc.)
- `/bundles`: Secured `.zip` files for customers.

## 🛠️ How to Update
To change the price or UPI ID, edit the `CONFIG` object in `script.js`.
